# To-Do List Web App

## 📌 About Project
This is Task 5 from Synent Technologies Internship.  
It is a simple To-Do List web application built using HTML, CSS, and JavaScript.

---

## 🧑‍💻 Developer
John Ayman Makram Nawar

---

## 🛠️ Technologies Used
- HTML5  
- CSS3  
- JavaScript (ES6)  
- localStorage  

---

## 🎯 Features
- Add new tasks  
- Delete tasks  
- Mark tasks as completed  
- Tasks saved using localStorage (data persists after refresh)  

---

## 💾 Storage
All tasks are stored in the browser using localStorage, so data remains even after page reload.
